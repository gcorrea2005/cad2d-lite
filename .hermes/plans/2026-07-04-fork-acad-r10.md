| Modo | Estado | Descripción |
|------|--------|-------------|
| **ENDpoint** | ✅ | Extremos de Line/Arc/Pline — prioridad 0 |

| **CENter** | ✅ | Centro de Circle/Arc — prioridad 2 |

| **TANgent** | ❌ | Tangente a Circle/Arc |

## FASE 2 — SETVAR (System Variables) — Arquitectura

AutoCAD R10 usaba ~120 variables de sistema accesibles vía el comando `SETVAR`.
Son el "registry" interno que controla TODO: snaps, grid, dimensiones, estado del drawing, preferencias.
Sin SETVAR no hay AutoCAD real.

### 2.0 — Engine SETVAR
- Diccionario global `sysvars: dict[str, Any]` con defaults de fábrica (ACAD.DWG template)
- Comando `SETVAR` → lista todas o `SETVAR <nombre>` → muestra valor
- `SETVAR <nombre> <valor>` → modifica
- `?` lista variables con wildcard: `SETVAR ? DIM*`
- Persistencia: se guardan/leen del `.cadlite` (sección `"sysvars"` en el JSON)
- Read-only vs read-write flags

### 2.3 — Integración con otros sistemas
- `OSMODE` → actualiza `_active_snaps` del SnapEngine
- `APERTURE` → redimensiona la caja del snap visual
- `PICKBOX` → redimensiona el pickbox del crosshair
- `ORTHOMODE` → toggle F8 ya lo usa, leer de SETVAR en vez de bool interno
- `GRIDMODE/SNAPMODE` → prender/apagar grid visual y snap
- `CLAYER` → sincronizado con `layer_manager.current_layer`
- `FILLETRAD/CHAMFERA/CHAMFERB` → valores default de las tools

### 2.4 — Archivos
- `src/model/sysvars.py` — definición de variables + defaults + validación
- Tests: `tests/test_sysvars.py` — bitmask OSMODE, roundtrip, read-only, wildcard

### 2.5 — LISTA MAESTRA DE IMPLEMENTACIÓN (orden de importancia)

#### BLOQUE A — IMPRESCINDIBLES (12 vars) — sin esto no hay ACAD

| # | Variable | Default | Por qué es crítica |
|---|----------|---------|-------------------|
| 1 | `OSMODE` | 0 | Bitmask de running OSNAP. La variable más importante de todo AutoCAD. Sin esto, los snaps son manuales uno por uno. |
| 2 | `APERTURE` | 10 | Tamaño en px de la cajita cuadrada que delimita la zona de snap. Si es 0 no hay snap visual. |
| 3 | `PICKBOX` | 3 | Tamaño del pickbox verde del crosshair. Controla precisión de selección. |
| 4 | `ORTHOMODE` | 0 | Ortho ON/OFF. Ya tenemos F8, hay que sincronizarlo con esta variable. |

| 6 | `CLAYER` | "0" | Capa actual. Sincronizado con LayerManager. Todo lo que dibujás va a esta capa. |
| 7 | `FILLETRAD` | 0 | Radio del empalme. Sin esto, FILLET siempre pregunta el radio. |
| 8 | `CHAMFERA` | 0 | Distancia 1 del chaflán. CHAMFER sin esto es inusable. |
| 9 | `CHAMFERB` | 0 | Distancia 2 del chaflán. |
| 10 | `TEXTSIZE` | 0.2 | Altura default del texto. Sin esto, TEXT siempre pregunta altura. |
| 11 | `OFFSETDIST` | -1 | Distancia de offset. -1 = "through" (pide punto). Con valor >0, OFFSET no pregunta distancia. |
