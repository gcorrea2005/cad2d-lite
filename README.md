# CAD 2D Lite

Desktop 2D CAD application built with Python + PySide6.

## Features
- Entities: line, arc, circle, polyline, text, dimensions
- Layers with color and visibility control
- Object snaps (endpoint, midpoint, center, intersection, nearest)
- Zoom/pan navigation
- DXF export
- Undo/redo

## Quick Start
```
pip install -r requirements.txt
python -m src.main
```
