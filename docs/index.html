Flujo de Trabajo Típico

1. Configurar unidades y límites

Menú SETTINGS → UNITS (Decimal, 2 decimales) → LIMITS (0,0 a 100,100)

2. Crear capas

LAYER → Make → "MUROS", color cyan. Repetir para "PUERTAS", "VENTANAS", "COTAS"

3. Dibujar geometría

DRAW → LINE, CIRCLE, RECTANGLE, POLYLINE según necesites. Con ORTHO (F8) activo.

4. Modificar

MOVE, COPY, ROTATE, MIRROR, SCALE, OFFSET, TRIM, EXTEND, FILLET, CHAMFER

5. Acotar y anotar

DRAW → DIMENSION (LINEAR), TEXT para etiquetas

6. Medir y verificar

INQUIRY → DIST (distancia), ID (info entidad), AREA (área poligonal)

7. Exportar

Ctrl+S (.cadlite) y FILE → Export DXF para compartir con AutoCAD

8. Imprimir

FILE → PLOT → Seleccionar impresora/PDF

Generación Programática de Planos

# scripts/generate_apto.py — generá planos de apartamentos con código from src.model.document import Document from src.model.entities.line import LineEntity from src.model.entities.text import TextEntity from src.io.cad_file import save_document doc = Document() doc.units = 'decimal' doc.precision = 2 # Muro doble: dos líneas paralelas muros = doc.layer_manager.add_layer('MUROS', '#00CCFF') doc.add_entity(LineEntity((0, 0), (10, 0), layer='MUROS')) doc.add_entity(LineEntity((0, 0.15), (10, 0.15), layer='MUROS')) save_document(doc, 'mi_apto.cadlite') # ¡Listo! Abrí el .cadlite en CAD 2D Lite

Pitfalls (Errores Frecuentes)

❌Lanzar en background en macOS → SIGSEGV 139. Qt GUI apps DEBEN correr en foreground.
❌Olvidar QColor import → NameError en paint(). Siempre: `from PySide6.QtGui import QColor`.
❌Lambda sin default arg → late-binding bug, todos los botones activan la última tool.
❌Nueva entidad sin tocar 4 archivos → datos perdidos en save/load, invisibles en undo/redo.

📜 HISTORIA DEL PROYECTO

Todo empezó como un "¿y si hacemos un CAD?" y terminó con 4,877 líneas y 30 herramientas. Así se cuenta la historia.

FASE A

Fundación — DRAW + VIEW

Esqueleto MVC básico. Entidades: Line, Circle, Arc, Polyline, Text, Dimension. Herramientas de dibujo clásicas: LINE, CIRCLE, ARC, PLINE, RECTANGLE, TEXT, DIM. CadView con zoom/pan, grid retro VGA, screen menu azul AutoCAD 10. DXF export inicial. Undo/redo funcional.

FASE B

MODIFY — El poder de editar

MOVE, COPY, ROTATE, DELETE, MIRROR, SCALE, OFFSET, TRIM, EXTEND, FILLET, CHAMFER. Matemáticas de intersección, proyección de puntos, cálculo de tangentes con atan2. Undo vía ModifyEntityCommand.

FASE C

UTILITY — Lo que faltaba

EXPLODE (polilínea → líneas), BREAK (partir línea en 2), ARRAY (grid rectangular), HATCH (relleno con líneas paralelas), PURGE (limpiar capas vacías). Zoom stack 50 niveles con ZOOM Previous.

FASE D

SETTINGS — Toques finales

POINT y SOLID (relleno poligonal con color). UNITS (5 tipos + precisión). LIMITS (límites del dibujo). PLOT (impresión vía QPrintDialog). Screen menu al 95%. Solo INSERT queda pendiente.

FUTURO

Lo que viene

INSERT (bloques/biblioteca), SNAP modes avanzados (midpoint, perpendicular, tangent), selección por ventana/crossing, UNDO mark/back, GRIPS para edición directa, export SVG/PDF, soporte para fuentes SHX, y quien sabe qué más.
