🎯 TRANSIENT OSNAP — Snap de un Solo Pick

Ademas del OSNAP persistente (OSNAP END,MID,INT que queda activo para siempre), DogCAD soporta transient OSNAP: escribis el nombre del snap en la command line mientras una herramienta esta activa, y el proximo pick usa SOLO ese snap. Despues del pick, volves a tus snaps normales. Es como pedirle "esta vez soloEndpoint".

Como funciona

;; Activa LINE y usa transient snaps para cada punto: LINE ;; Escribi END y Enter → el proximo click snappea SOLO a endpoints END ;; Click en un extremo... la linea empieza ahi ;; Escribi PER y Enter → ahora el cursor busca perpendicular PER ;; Click en la linea objetivo → pie de perpendicular perfecto ;; Escribi MID y Enter → punto medio MID ;; Click en una linea → punto medio exacto ;; Esc para cancelar la herramienta

Snaps transient disponibles

END MID CEN INT PER NEA QUA TAN NOD INS

Diferencia vs OSNAP persistente

ModoComandoDuracionCuando usarlo
PersistenteOSNAP END,MID,INTHasta que lo cambiesDibujo general: siempre querés snap a extremos y centros
TransientEND (en medio de LINE)Solo el proximo pickUn punto especifico: "este punto es perpendicular", "acá necesito el centro"

Pro tip: El transient OSNAP reemplaza los snaps activos para ese pick, no los complementa. Si tenes OSNAP END,MID,INT y escribis PER, el proximo pick SOLO buscara perpendiculares — ignora END/MID/INT.

SAVEAS DXF — Exportá a formato de intercambio

El comando SAVEAS ahora detecta automáticamente la extensión. Si guardás como mi_plano.dxf, exporta DXF en vez de .cadlite. Sin pasos extra.

;; Guardar como .cadlite (formato nativo JSON) SAVEAS mi_plano → mi_plano.cadlite ;; Guardar como .dxf (intercambio con AutoCAD) SAVEAS mi_plano.dxf → mi_plano.dxf (detecta .dxf autom.) ;; O usá el diálogo: FILE → SAVEAS → elegí "DXF (*.dxf)" en el filtro

Limitaciones conocidas

La importación de DWG trae geometría 2D básica: LINE, CIRCLE, ARC, LWPOLYLINE, TEXT, MTEXT, INSERT, POINT. Entidades 3D, layouts, paper space, xrefs, hatches complejos y dimensiones no se importan — se saltan silenciosamente. Para planos arquitectónicos y estructurales 2D, funciona perfecto.

0. Bienvenido a DogCAD

¿Qué es un CAD?

CAD significa Computer-Aided Design — diseño asistido por computadora. Es un programa para dibujar con precisión milimétrica. Planos de casas, piezas mecánicas, diagramas eléctricos, cerchas de techo... lo que sea que necesite medidas exactas. A diferencia de Paint o Illustrator, en un CAD cada línea tiene coordenadas reales: sabés exactamente cuánto mide, dónde empieza y dónde termina.

¿Por qué DogCAD?

Porque AutoCAD cuesta USD $2,000+ al año. DogCAD es gratis, open source, y corre 100% en tu computadora sin internet. Hecho en Colombia 🇨🇴 por un ingeniero civil que se cansó de las suscripciones. Tiene 35 herramientas, exporta a DXF y PDF, y se maneja exactamente igual que el AutoCAD de los 90.

1. La Interfaz Explicada

Cuando abrís DogCAD ves esto. Vamos por partes.

Screen Menu (panel azul a la derecha)

Es el menú vertical azul marino. Tiene categorías: DRAW (dibujar), EDIT (modificar), DISPLAY (zoom/pan), INQUIRY (medir), LAYER (capas), SETTINGS (configuración). Clickeás una categoría y se despliegan las herramientas. Es idéntico al menú del AutoCAD R10 de 1988. Los veteranos del CAD se sienten en casa.

Área de Dibujo (el fondo negro)

Es el espacio negro donde dibujás. Tiene un grid (cuadrícula) de puntos azules oscuros para orientarte. La cruceta blanca sigue tu mouse. El cuadradito verde en el centro de la cruceta es el pickbox — lo que usás para seleccionar entidades y hacer snap.

Command Line (barra inferior)

Es la barra donde escribís comandos. Tiene un cursor verde que parpadea. Acá podés escribir LINE 0,0 1000,0 en vez de usar el mouse. Los comandos son en inglés (como en todos los CAD del mundo). Usá ↑↓ para navegar el historial. Esc para cancelar y volver al prompt.

Status Bar (esquina inferior)

Muestra: capa actual, color actual, tipo de línea, y las coordenadas X,Y del cursor. También indica si SNAP (F9), GRID (F7) u ORTHO (F8) están activados.

3. Coordenadas — El Lenguaje del CAD

En un CAD todo se mide con coordenadas X,Y. El origen (0,0) está en la esquina inferior izquierda. X crece hacia la derecha, Y crece hacia arriba. Hay tres formas de dar coordenadas:

Absolutas: X,Y

Medís desde el origen (0,0). LINE 0,0 1000,500 dibuja una línea desde el origen hasta el punto X=1000, Y=500. Simple. Predecible.

Relativas: @dx,dy

Medís desde el ÚLTIMO punto que dibujaste (LASTPOINT). La @ significa "desde donde estoy ahora". LINE 0,0 @1000,0 = "desde 0,0, moveme 1000 en X y 0 en Y". Llega al mismo punto (1000,0) que la absoluta, pero sin calcular.

;; Estas dos secuencias dibujan exactamente lo mismo: ;; Con absolutas: LINE 0,0 1000,0\n LINE 1000,0 1000,500\n LINE 1000,500 0,500\n LINE 0,500 0,0 ;; Con relativas (mucho más fácil): LINE 0,0 @1000,0\n @0,500\n @-1000,0\n @0,-500

Polares: @distancia<ángulo

Medís con distancia y ángulo. @200<45 = "200 unidades a 45 grados". 0° es hacia la derecha (este), 90° es hacia arriba (norte), 180° izquierda, 270° abajo.

;; Triángulo equilátero de lado 300 (ángulos internos 60°): LINE 0,0 @300<0 → base horizontal @300<120 → lado derecho (120° desde horizontal = 60° interno) @300<240 → cierra (240° = -120° desde horizontal)

Ejercicio: Dibujá un pentágono regular con polares. Pista: cada lado gira 72° (360/5). LINE 0,0 @200<0 @200<72 @200<144 @200<216 @200<288.

4. Capas (Layers) — Organizar tu Dibujo

Imaginá que dibujás en hojas de papel transparente apiladas. Cada hoja es una capa. Una capa para muros, otra para ejes, otra para cotas, otra para texto... Podés prender y apagar capas para ver solo lo que te interesa.

TEMPLATE — Tu punto de partida

TEMPLATE crea 12 capas listas para arquitectura: 0 (default), EJES (rojo, CENTER), MUROS (blanco), PUERTAS (amarillo), VENTANAS (cyan), COTAS (rojo), TEXTOS (verde), MOBILIARIO (gris), INSTALACIONES (magenta), CUBIERTA (azul), SANITARIO (cyan oscuro), ELECTRICO (naranja). Empezá siempre con TEMPLATE.

Comandos de capa

CLAYER MUROS → cambiarme a la capa MUROS LAYER ? → listar todas las capas LAYER NEW INSTALACIONES → crear capa nueva LAYER OFF EJES → apagar la capa EJES LAYER ON EJES → prenderla de nuevo LAYER COLOR MUROS 4 → cambiar color de la capa MUROS a cyan LAYER SET 0 → volver a capa default

Regla de oro: Siempre dibujá en la capa correcta. Ejes en EJES, muros en MUROS. Si dibujás todo en la capa 0, después no podés apagar solo los ejes para plotear.

Ejercicio: Capas en acción

TEMPLATE ;; Dibujar ejes CLAYER EJES\n LINETYPE CENTER\n COLOR 1 LINE 0,500 1000,500 → eje horizontal rojo con rayas LINE 500,0 500,1000 → eje vertical rojo con rayas ;; Dibujar muros CLAYER MUROS\n LINETYPE CONTINUOUS\n COLOR 7 RECTANG 200,200 800,800 → muro blanco continuo ;; Apagar ejes para ver solo muros LAYER OFF EJES\n ZOOM E ;; Prender ejes de nuevo LAYER ON EJES\n ZOOM E

5. Snap (OSNAP) — Precisión Milimétrica

Sin snap, dibujar es como tratar de enhebrar una aguja con guantes de boxeo. El snap atrae el cursor a puntos exactos de las entidades: extremos, centros, intersecciones. Es lo que separa un garabato de un plano profesional.

;; La combinación mágica — cubre el 90% de los casos: OSNAP END,MID,INT ;; F9 activa/desactiva el snap rápido ;; OSNAP OFF desactiva todo ;; Ver configuración actual: SETVAR OSMODE

Ejercicio: Precisión con snap

;; 1. Dibujá un círculo y una línea cualquiera CIRCLE 500,500 200\n LINE 100,100 900,900 ;; 2. Activá snap: OSNAP END,MID,CEN,INT OSNAP END,MID,CEN,INT ;; 3. Dibujá una línea DESDE el centro del círculo HASTA el midpoint de la línea LINE → acercá el cursor al centro del círculo (glyph ○+) → click → acercá el cursor al medio de la línea (glyph △) → click → ¡línea perfecta!

6. Modificar — Editar sin Borrar

En CAD no borrás y volvés a dibujar. Modificás. Es más rápido y preciso. Estas son las herramientas de modificación que más vas a usar.

ERASE — Borrar

ERASE → click en entidad → Enter o click derecho ;; O seleccioná primero y apretá Supr

MOVE — Mover

MOVE → seleccioná entidad/es → Enter → click punto base (desde dónde) → click punto destino (hacia dónde)

COPY — Copiar

COPY → igual que MOVE pero deja el original

ROTATE — Rotar

ROTATE → seleccionar → punto base → ángulo (ej: 90)

MIRROR — Espejar

MIRROR → seleccionar → 2 clicks para definir eje de simetría

OFFSET — Crear paralela

OFFSET → distancia (ej: 150) → click en línea → click al lado ;; La distancia se guarda en OFFSETDIST. Cambiala con: SETVAR OFFSETDIST 200

TRIM y EXTEND — Cortar y alargar

TRIM → click en línea borde (la que corta) → Enter → click en la parte de la línea que querés eliminar EXTEND → click en línea borde (hasta dónde) → Enter → click en la línea que querés alargar

Ejercicio: Muro doble

;; Dibujar un rectángulo de muro simple RECTANG 1000,1000 4000,5000 ;; Offset hacia adentro para crear muro doble OFFSET 150 → click en el rectángulo → click hacia adentro ;; Dibujar una línea que atraviese los muros LINE 500,3000 4500,3000 ;; Trim para limpiar el segmento interior ;; (la línea debería cortarse al entrar y salir del muro interior)

7. Acotar (Dimension) — Poner Medidas

Un plano sin cotas es un dibujo bonito pero inútil. Las cotas le dicen al constructor exactamente cuánto mide cada cosa.

DIM — Cota lineal

CLAYER COTAS\n COLOR 1 DIM → click primer punto → click segundo punto → click dónde querés el texto de cota

DIMALIGNED — Cota alineada

DIMALIGNED → igual que DIM pero la cota queda paralela a los puntos

DIMRADIUS / DIMDIAMETER

DIMRADIUS → click en círculo/arco → muestra "R 200.00" DIMDIAMETER → click en círculo → muestra "⌀ 400.00"

DIMBASELINE — Cadena de cotas

;; Primero una cota normal para fijar el origen: DIM ;; Después DIMBASELINE para seguir acotando desde ese origen: DIMBASELINE → click siguiente punto → click siguiente → ...

Ajustar tamaño de cotas

;; Si las cotas se ven muy chicas o muy grandes: SETVAR DIMSCALE 50 → escala general (default: 1) SETVAR DIMTXT 3 → altura del texto (default: 2.5) SETVAR DIMASZ 3 → tamaño de flecha (default: 2.5) SETVAR ? DIM* → ver todas las variables de dimensión

8. Tu Primer Plano Real — Apartamento Paso a Paso

Llegó el momento. Vamos a dibujar un apartamento de 10m × 7m con muros dobles, divisiones interiores, puertas, ventanas, cotas y exportación a PDF. Este es el mismo flujo de trabajo que usa un arquitecto en AutoCAD. Vas a tardar ~30 minutos. El resultado es un plano listo para plotear.

Paso 1: Template y Capas

TEMPLATE → 12 capas: EJES, MUROS, PUERTAS, VENTANAS, COTAS, etc. LAYER ? → verificá que se crearon

Paso 2: Ejes

CLAYER EJES\n LINETYPE CENTER\n COLOR 1 ;; Ejes verticales LINE 1500,0 1500,8000 LINE 5500,0 5500,8000 LINE 10500,0 10500,8000 ;; Ejes horizontales LINE 0,1000 12000,1000 LINE 0,4000 12000,4000 LINE 0,7500 12000,7500 ZOOM E

Paso 3: Muros Exteriores

CLAYER MUROS\n LINETYPE CONTINUOUS\n COLOR 7 ;; Rectángulo exterior de 9m × 6.5m (medido entre ejes) RECTANG 1500,1000 10500,7500 ;; Muro doble: offset 150mm hacia adentro OFFSET 150 → click en el rectángulo → click hacia adentro del edificio

Paso 4: Muros Interiores

;; Muro divisorio entre zona social y habitaciones LINE 1500,4000 10500,4000 OFFSET 100 → doble muro interior de 100mm ;; Muro de baño (vertical) LINE 5500,1150 5500,4000 OFFSET 100 ;; Limpiar intersecciones con TRIM TRIM → click en bordes → Enter → click en líneas a cortar

Paso 5: Puertas

;; Crear vanos (huecos) en muros con BREAK BREAK → click en muro → click donde termina el vano (900mm) ;; Insertar puertas de 90cm CLAYER PUERTAS ;; Posicioná la cruceta donde querés la puerta y ejecutá: DOOR 0.9 → puerta en LASTPOINT (arco + hoja) ;; Si la puerta queda orientada al revés, rotala: ROTATE → seleccionar puerta → punto base → 180 ;; Repetí para todas las puertas (entrada, baño, habitaciones)

Paso 6: Ventanas

CLAYER VENTANAS\n COLOR 5 ;; Ventana de 1.20m en fachada principal WINDOW 1.2 → ventana con marco y mainel ;; Copiar a otras posiciones COPY → seleccionar ventana → punto base → punto destino ;; Repetí para fachada posterior y laterales

Paso 7: Acotar el Plano

CLAYER COTAS\n COLOR 1 ;; Ajustar tamaño de cotas para que se lean bien SETVAR DIMSCALE 50\n SETVAR DIMTXT 2.5 ;; Cotas horizontales (fachada principal) DIM → esquina izq muro ext → esquina der muro ext → abajo ;; Cotas verticales DIM → esquina inf muro ext → esquina sup muro ext → izquierda ;; Cotas interiores DIM → medir ancho de cada habitación DIMBASELINE → cadena desde el origen

Paso 8: Texto y Mobiliario (opcional)

CLAYER TEXTOS\n COLOR 3 TEXT → click donde querés el texto → "SALA-COMEDOR", "COCINA", "ALCOBA 1", "BAÑO" SETVAR TEXTSIZE 300 → ajustar altura de texto para escala 1:50

Paso 9: Exportar a PDF

;; Configurar límites del dibujo para el plot LIMITS 0,0 12500,9000 ZOOM E ;; Plotear PLOT → elegí A3, escala 1:50, orientation landscape ;; El PDF se genera y se abre solo. ¡Listo!

Paso 10: Guardar

SAVEAS apartamento_1 → guarda como apartamento_1.cadlite

¡Felicitaciones! Acabás de producir tu primer plano arquitectónico en DogCAD. En un estudio de arquitectura esto mismo toma horas en AutoCAD y cuesta USD $2000+/año. A vos te tomó 30 minutos y $0.

9. Automatización — Scripts .scr

Si tenés que dibujar la misma estructura muchas veces (cerchas, pórticos, grillas), no la dibujes a mano. Escribí un archivo .scr con los comandos y ejecutalo. Es como darle una lista de instrucciones a DogCAD para que dibuje solo.

Ejemplo: Cercha Warren de 6 paneles

; Guardá esto como cercha.scr LAYER NEW CERCHA\n LAYER SET CERCHA\n COLOR 4 ; Cordón inferior — 6 paneles de 1000mm LINE 0,0 @1000,0\n @1000,0\n @1000,0\n @1000,0\n @1000,0\n @1000,0 ; Cordón superior — altura 800mm LINE 0,0 @500,800\n @1000,0\n @1000,0\n @1000,0\n @1000,0\n @500,-800 ; Diagonales Warren (alternadas / \) LINE 1000,0 500,800\n LINE 1000,0 1500,800 LINE 2000,0 1500,800\n LINE 2000,0 2500,800 LINE 3000,0 2500,800\n LINE 3000,0 3500,800 LINE 4000,0 3500,800\n LINE 4000,0 4500,800 LINE 5000,0 4500,800\n LINE 5000,0 5500,800 ; Montantes verticales LINE 1000,0 1000,800\n LINE 2000,0 2000,800 LINE 3000,0 3000,800\n LINE 4000,0 4000,800\n LINE 5000,0 5000,800 ZOOM E

Cargar el script

;; FILE → SCRIPT en el menú, o: SCRIPT cercha.scr ;; DogCAD ejecuta comando por comando. Al terminar, ZOOM E para ver.

Generador Python para cerchas complejas

Para cerchas con anchos de vano variables, usá el generador:

python templates/truss-generator.py --out mi_cercha.scr \ --widths 900,900,900,825,900,900,900,470 \ --diag up --invert-at 4 --height 1000 ;; Esto genera un .scr con 19 vanos, anchos variables, ;; diagonales hacia arriba, invertidas a partir del vano 4.

10. DogLISP para Power Users

DogCAD tiene un intérprete de Lisp/Scheme embebido. Si sabés programar (o querés aprender), podés crear tus propias funciones de dibujo. Cualquier texto que empiece con ( en la command line se ejecuta como Lisp.

Primeros pasos en Lisp

;; Dibujar una línea con Lisp (line (p 0 0) (p 1000 500)) ;; Dibujar un círculo (circle (p 500 500) 200) ;; Cambiar de capa (layer "set" "MUROS") ;; Activar snaps (osmode "END,MID,INT") ;; Calcular algo (cal "100*2") → 200

Definir tu propia función

;; Función que dibuja una grilla de columnas (defun grilla (x y cols filas sep) (if (> filas 0) (progn (grilla-fila x y cols sep) (grilla x (+ y sep) cols (- filas 1) sep)))) (defun grilla-fila (x y n sep) (if (> n 0) (progn (rectang (p x y) (p (+ x 30) (+ y 30))) (grilla-fila (+ x sep) y (- n 1) sep)))) ;; Usarla: grilla de 5×4 columnas de 30×30cm cada 500cm (grilla 0 0 5 4 500)

Cargar archivos .lsp

APPLOAD → diálogo para elegir archivo .lsp LSPLOAD mis_funciones.lsp → cargar directamente LISP (mi_funcion 100 200) → ejecutar una expresión ;; O simplemente escribí la expresión Lisp en la command line: (mi_funcion 100 200)

🔧 Troubleshooting — Problemas Comunes

ProblemaSolución
"No veo lo que dibujé" ZOOM E — probablemente dibujaste fuera del viewport actual.
"El snap no funciona" SETVAR OSMODE — si es 0, activalo: OSNAP END,MID,INT o F9.
"Las cotas se ven enormes / microscópicas" SETVAR DIMSCALE 50 — ajustá la escala. Probar 10, 50, 100 según el dibujo.
"No puedo seleccionar una entidad" Si está en una capa bloqueada: LAYER UNLOCK nombre_capa.
"Escribí un comando y no pasó nada" Los comandos son en inglés (LINE, no LINEA). ¿Está bien escrito? ¿Diste Enter?
"El offset no funciona" El flujo es: OFFSET → distancia → Enter → click en entidad → click al lado. A veces requiere 2 Enters después de la distancia.
"El trim no corta" TRIM necesita: (1) click en línea(s) BORDE → Enter, (2) click en la PARTE a eliminar. Si no corta, la línea no cruza el borde.
"La app crashea al abrir en macOS" QT_OPENGL=software python -m src.main — fuerza render por software.
"No encuentro el PDF que plotée" Se abre solo al generarse. Si no, revisá el directorio donde está el .cadlite.
"El DWG no abre / da error" Instalá LibreDWG: brew install libredwg. Si el DWG es muy nuevo (2018+), instalá ODA FileConverter como fallback. Usá DWGFIN (no DXFIN) para DWGs.

TipDetalle
OSNAP más útilOSNAP END,MID,INT — cubre el 90% de los casos. Activá con F9.
